# Wedding Invitation Platform - Product Context

## Core Value Proposition

A wedding invitation platform that transforms the traditional paper invitation into an interactive digital experience. Couples create beautiful, animated invitations without design skills, distribute them effortlessly, and track RSVPs in real-time.

## User Personas

### Primary Users

**The Couple**
- Age: 25-40
- Tech Savvy: Moderate to high
- Goals: Beautiful invitation, easy distribution, clear RSVP tracking
- Pain Points: Paper invitations expensive, tracking responses tedious, limited design options

**Wedding Planners**
- Managing multiple events
- Need bulk guest management
- Want analytics for attendance forecasting
- Pain Points: Coordinating RSVPs across events, manual tracking

### Secondary Users

**Wedding Guests**
- Receiving and viewing invitations
- Submitting RSVPs
- Accessibility requirements
- Mobile-first experience needed

## User Journeys

### Journey 1: Create First Invitation
```
1. Sign up / Log in
   ↓
2. Browse templates
   ↓
3. Select template
   ↓
4. Customize content (names, date, venue)
   ↓
5. Preview on desktop/mobile
   ↓
6. Publish invitation
   ↓
7. Add guests
   ↓
8. Send invitations
   ↓
9. Track RSVPs
```

### Journey 2: Guest RSVP
```
1. Receive invitation link (WhatsApp/Email)
   ↓
2. Click link → View invitation
   ↓
3. Watch animations, browse sections
   ↓
4. Click RSVP button
   ↓
5. Fill form (name, attendance, dietary, message)
   ↓
6. Submit
   ↓
7. See confirmation
```

### Journey 3: AI-Assisted Creation
```
1. Start event creation
   ↓
2. Click "AI Assist" or describe vision
   ↓
3. AI generates content suggestions
   ↓
4. Review and edit suggestions
   ↓
5. Apply to invitation
   ↓
6. Fine-tune individual sections
```

### P0 - Must Have
- Template browsing and selection
- Basic event customization
- Invite code generation
- RSVP form and submission
- Email/link distribution

### P1 - Should Have
- Advanced customization (colors, fonts)
- Guest import (CSV)
- RSVP analytics
- Multiple template variants
- Mobile responsiveness

### P2 - Nice to Have
- AI content generation
- RSVP reminders
- Guest chat/invite interactions
- Analytics dashboards
- Premium templates

### P3 - Future
- QR code sharing
- Video invitations
- Gift registry integration
- Multi-language support
- Print-to-order

## Success Metrics

| Metric | Target |
|--------|--------|
| Template conversion rate | >60% template selection → publish |
| RSVP completion rate | >75% of invited guests RSVP |
| Time to publish | <15 minutes for first event |
| Mobile engagement | >50% viewed on mobile |
| AI acceptance rate | >40% AI suggestions accepted |

## Competitive Landscape

### Direct Competitors
- **Milyon** - Korean market, beautiful templates
- **WithJoy** - US market, comprehensive features
- **Paperless Post** - Premium positioning

### Indirect Competitors
- Canva templates
- Zola wedding suite
- Basic Google Forms + links

### Differentiation Points
1. **Animation-first** - Unique scroll-triggered animations
2. **Guest management** - Built-in RSVP tracking
3. **AI assistance** - Content generation for busy couples
4. **Regional focus** - Vietnamese market expertise
